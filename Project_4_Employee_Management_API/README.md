# Employee Management API

My second **FastAPI** mini project, building upon the Student API to explore advanced RESTful API concepts, modular code architecture, and complete CRUD operations on employee records.

## Features

- **CRUD Operations**:
  - Create an employee
  - Get all employees
  - Get an employee by ID
  - Update employee details
  - Delete an employee
- Middleware
- Background Tasks
- Request validation using Pydantic
- Clean and modular API structure
