# Student Management API

A simple RESTful API built with **FastAPI** to perform CRUD operations on student records. This project demonstrates FastAPI fundamentals, request validation, dependency injection, and proper HTTP responses.

## Features

- Create a student
- Get all students
- Get a student by ID
- Update student details
- Delete a student
- Request validation using Pydantic
- Clean and modular API structure

## Tech Stack

- Python
- FastAPI
- Pydantic

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
